## 🚀 Your Challenge

Make your **first contribution** to this repository by adding your name to the contributors list below.

You will practice:

* Creating a branch
* Making a change
* Committing your change
* Pushing to GitHub
* Creating a Pull Request
* Getting your contribution merged

---

## 🛠️ How to Contribute

### 1. Fork this repository

Click the **Fork** button at the top-right of this repository.

This creates your own copy of the repository.

---

### 2. Clone your fork

Copy your repository URL and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Then move into the project:

```bash
cd REPOSITORY_NAME
```

---

### 3. Create a new branch

Create a branch using your name:

```bash
git checkout -b add-your-name
```

For example:

```bash
git checkout -b add-dibyendu
```

---

### 4. Add your name

Open the `CONTRIBUTORS.md` file.

Add yourself to the list using this format:

```text
- Your Name — College / Institution
```

Example:

```text
- Dibyendu Chatterjee — ABC College
```

**Please don't modify or delete someone else's entry.**

---

### 5. Commit your change

Check what changed:

```bash
git status
```

Add the changes:

```bash
git add .
```

Create your commit:

```bash
git commit -m "Add Your Name to contributors"
```

---

### 6. Push your branch

```bash
git push origin add-your-name
```

---

### 7. Create a Pull Request

Go to your GitHub repository.

You should see an option to create a **Pull Request**.

Create the Pull Request from:

```text
your-branch → main
```

In the description, you can write:

> Added my name to the contributors list as part of the Git & GitHub workshop.

Then click **Create Pull Request**.

---

### 8. Wait for the merge 🎉

The organizers will review the Pull Request.

Once approved, your contribution will be merged into the main repository.

Congratulations — you've made your **first collaborative GitHub contribution!**

---

## 📋 Contribution Rules

Please follow these simple rules:

1. Add only your own name.
2. Don't delete or modify other participants' entries.
3. Use a separate branch for your contribution.
4. Use a meaningful commit message.
5. Don't upload passwords, API keys, or other secrets.
6. Keep your Pull Request focused on this challenge.
